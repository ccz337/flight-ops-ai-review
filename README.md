# Flight Ops AI Review



> 面向消费者的航班与航空公司历史运行稳定性决策支持原型。



## 项目定位



本项目面向需要在多个航班或航空公司之间做选择的出行消费者。产品计划结合出发地、目的地、出行时间和用户关注点，依据历史取消率、延误率、平均延误时长、准点率及有效样本量，比较候选航班或航空公司的运行稳定性，为消费者的购票决策提供参考。



## 当前MVP范围



当前第一版计划仅使用 `nycflights13` 公开历史数据，因此只能演示该数据所覆盖的纽约出发航班场景。具体数据版本、时间范围、机场及记录数量，将在独立取得并核验数据后补充。



当前版本不能覆盖所有出发地，也不能评价当前或未来的具体航班。未来若扩展到其他地区，需要接入更多出发地和更新时段的数据，并重新验证指标口径与推荐质量。



## 计划使用的指标



\- 取消率

\- 延误率

\- 平均延误时长

\- 准点率

\- 有效样本量



各项指标的阈值、分母和缺失值处理方式将在指标合同中单独定义。



## AI职责



AI不直接计算事实指标。计划由程序先完成数据计算与校验，再由AI生成消费者易懂的比较说明、证据引用和风险提示。



当样本不足、候选条件不可比或证据缺失时，系统应拒绝给出强推荐。



## 项目边界



本项目是个人作品集原型，尚未经过真实用户访谈、业务验证或线上使用，不代表航空公司的真实生产系统。



运行稳定性只是消费者选择航班或航空公司的一个参考维度。本项目暂不覆盖票价、服务、行李、航线便利性和安全等因素，也不评选绝对意义上的“最佳航司”。



本项目受课程学习启发，但将在独立目录中重新定义和实现，不复制课程代码、模板或讲义。AI协助与本人实际完成内容将如实记录。
