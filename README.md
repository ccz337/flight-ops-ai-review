# Flight Ops AI Review

> 面向消费者的航班与航空公司历史运行稳定性决策支持原型。

## 项目定位

本项目面向需要在多个航班或航空公司之间进行选择的出行消费者。

产品计划根据出发地、目的地和出行时间，在可比条件下使用历史取消率、
延误率、平均延误时长、准点率和有效样本量，比较候选航班或航空公司的
运行稳定性，为消费者的购票决策提供一个参考维度。

## 当前MVP范围

当前MVP使用CRAN发布的`nycflights13 1.0.2`公开历史数据，只能演示
2013年从纽约三座机场出发的航班：

- EWR：纽瓦克自由国际机场
- JFK：约翰·肯尼迪国际机场
- LGA：拉瓜迪亚机场

当前数据包含336,776条航班记录。项目第一版使用：

- `flights`：航班记录
- `airlines`：航司代码与名称
- `airports`：机场信息

当前版本不能覆盖所有出发地，也不能评价当前或未来的具体航班。

## 计划使用的指标

- 取消率
- 延误率
- 平均延误时长
- 准点率
- 有效样本量

各项指标的阈值、分母和缺失值处理方式将在指标合同中单独定义。

## AI职责

AI不直接计算事实指标。

程序将先完成数据计算和校验，再由AI根据经过验证的结构化指标生成：

- 消费者易懂的比较说明
- 对应的证据引用
- 数据限制和风险提示
- 下一步调查建议

当样本不足、候选条件不可比或证据缺失时，系统应拒绝给出强推荐。

## 数据复现

当前环境使用Python 3.13，并固定以下依赖：

- pandas 2.3.3
- pyreadr 0.5.7

Windows PowerShell运行方式：

```powershell
python -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r "requirements.txt"
& ".\.venv\Scripts\python.exe" "src\fetch_data.py"
```

数据版本、字段、行数和文件哈希记录在`data/manifest.json`。

原始数据位于`data/raw/`，不会提交到Git。详细说明见`data/README.md`。

## 项目边界

本项目是个人作品集原型，尚未经过真实用户访谈、业务验证或线上使用，
不代表航空公司的真实生产系统。

历史运行稳定性只是消费者选择航班或航空公司的一个参考维度。本项目不覆盖：

- 票价
- 服务
- 行李政策
- 航线便利性
- 航空安全

本项目不评选绝对意义上的“最佳航司”，也不能使用2013年历史数据直接指导
当前真实购票。
