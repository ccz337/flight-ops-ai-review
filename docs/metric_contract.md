# 航司运行稳定性指标合同 v0.1

## 1. 使用目的

本项目使用历史航班数据，帮助消费者比较候选航班或航司的运行稳定性。

当前版本仅使用 `nycflights13 1.0.2` 中2013年从纽约三座机场（EWR、JFK、LGA）出发的航班数据。因此，分析结果只用于验证产品与指标框架，不能代表航司当前表现，也不能直接外推到其他出发地或年份。

## 2. 筛选范围

每次比较必须明确以下条件：

- 日期范围

- 始发机场

- 目的地

- 候选航司

航司之间的比较应使用相同的始发机场、目的地和日期范围，避免把不同航线或时间段的差异误认为航司差异。

## 3. 核心指标

### 3.1 计划航班量

筛选范围内的全部航班记录数量。

计划航班量是取消率的分母，也是判断样本是否充足的基础。

### 3.2 取消航班量

`dep_time` 为空的航班数量。

当前数据没有单独的取消状态字段，因此使用没有实际起飞时间作为取消的代理定义。

### 3.3 取消率

计算公式：

`取消航班量 ÷ 计划航班量`

取消率越低，表示历史样本中的计划执行情况越稳定。

### 3.4 有效到达样本量

`arr_delay` 不为空的航班数量。

到达延误率、到达准点率等到达指标只能使用具有实际到达延误数据的航班作为分母。

### 3.5 到达延误率

计算公式：

`arr_delay > 15分钟的航班量 ÷ 有效到达样本量`

本项目将实际到达时间比计划到达时间晚超过15分钟定义为到达延误。

### 3.6 到达准点率

计算公式：

`arr_delay <= 15分钟的航班量 ÷ 有效到达样本量`

在相同有效样本范围内，到达延误率和到达准点率互为补数，因此不能在综合评价中把两者当作两个独立指标重复计权。

### 3.7 平均延误时长

只对 `arr_delay > 15分钟` 的延误航班计算平均到达延误分钟数。

该指标回答“已经发生明显延误时，平均延误多长时间”，不能与所有有效航班的平均到达延误混为一谈。

### 3.8 延误样本量

`arr_delay > 15分钟` 的航班数量。

报告必须同时展示计划航班量、有效到达样本量和延误样本量，不能只展示百分比。

## 4. 最低样本规则

原型阶段暂定：候选航司在当前比较条件下至少需要30个有效到达样本。

少于30个有效样本时，系统可以展示原始指标，但必须提示样本不足，不给出明确的优劣推荐。

30只是MVP的产品规则，不代表已经完成统计显著性验证。

## 5. 第一版决策方式

第一版分别展示：

- 计划航班量

- 取消率

- 到达延误率

- 到达准点率

- 平均延误时长

- 对应样本量

第一版不创建未经用户研究和统计验证的综合“稳定性分数”，避免用主观权重制造看似精确的排名。

## 6. 解释边界

指标反映的是特定历史数据范围内的运行表现，不代表因果关系，也不能证明延误一定由航司自身造成。

本项目不包含价格、服务、行李政策、安全水平和实时航班状态，因此不能替代消费者的完整购票判断。
